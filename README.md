# КЛАД · Лов на съкровища

Практическа част от магистърската теза на **Тони Петкова**: методически модел „Лов на съкровища“ с QR кодове за самостоятелна математика в **5. клас**.

## Какво има вътре

- Бранд **КЛАД** с български интерфейс
- **Пълна учебна програма** за 5. клас: срокове → теми → уроци → нива (лесно / средно / трудно) → QR станции
- Учителски кабинет за собствени ловни маршрути (localStorage)
- Ученически поток: сканиране → задача → подсказка → следваща станция

Каталожните QR връзки са къси (`/play?c=lessonId&lv=easy&n=0`) и четат задачите от вградения каталог — не набъбват в URL.

## Стартиране

```bash
npm install
npm run dev
```

Dev сървър: **http://127.0.0.1:3847**

Пресъздаване на каталога (ако пипаш генератора):

```bash
npm run curriculum:generate
```

## Структура на съдържанието

Генерира се от `scripts/generate-curriculum.mjs` → `src/data/curriculum.json`.

Типично покритие: **2 срока · ~10 теми · ~40 урока · 3 нива · ~5 станции** на ниво.

## Маршрути

| Път | Роля |
| --- | --- |
| `/` | Начална страница |
| `/curriculum` | Разглеждане по срок / тема / урок |
| `/curriculum/[lessonId]` | Нива, станции, QR лист |
| `/play?c=&lv=&n=` | Ученическа станция (каталог) |
| `/play?d=&n=` | Ученическа станция (кодиран собствен лов) |
| `/teacher` | Собствени ловни маршрути |
