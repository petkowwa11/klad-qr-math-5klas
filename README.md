# КЛАД · Лов на съкровища

Практическа част от магистърската теза на **Тони Петкова**: методически модел „Лов на съкровища“ с QR кодове за самостоятелна математика в **5. клас**.

Учителят създава маршрут от станции (задача + подсказка). Всяка станция получава QR код. Учениците сканират, решават, разкриват подсказка при нужда и продължават към следващата станция.

## Стек

- Next.js (App Router) + TypeScript
- Tailwind CSS + shadcn/ui
- Локално съхранение (`localStorage`) + споделими URL-и с компресирани данни (без акаунт и без база)

## Стартиране

```bash
npm install
npm run dev
```

Приложението слуша на **http://127.0.0.1:3847**.

## Потоци

1. **Начало** — бранд КЛАД и вход към кабинета / демо лова.
2. **Учител** (`/teacher`) — списък с маршрути, редакция на станции, пренареждане, QR лист за печат/изтегляне, преглед на ученическия екран.
3. **Ученик** (`/play?d=…&n=…`) — задача, подсказка, отбелязване като решена, преход към следваща станция.

Демо маршрутът **„Дроби в двореца“** се зарежда автоматично при първо отваряне.
