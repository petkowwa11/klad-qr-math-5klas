# КЛАД · Лов на съкровища

Практическа уеб-среда към магистърската теза на **Тони Петкова** — методически модел **„Лов на съкровища“** за самостоятелна работа по математика в **5. клас** чрез QR станции, вход с роли и учителски портал за напредък/пропуски.

## Стартиране

```bash
npm install
cp .env.example .env   # ако нямаш .env
npx prisma migrate dev
npm run db:seed
npm run dev
```

Отвори **http://127.0.0.1:3847**.

### Ученици

- Клас: **5**
- Паралелка: **а / б / в / г**
- Парола = **номер в класа**: `1`, `2` или `3` (по 3 ученици на паралелка, общо 12)

Пример: паралелка **а**, парола **1** → Ана Димитрова.

## Потоци

1. **Начало** — два QR кода (абсолютни URL към `/login/student` и `/login/teacher`).
2. **Ученик** — вход → портал → учебна програма / станции с проверка на отговор; напредъкът се записва в SQLite.
3. **Учител** — вход → портал само със своите ученици: верни/грешни/недовършени и списък „къде да наблегнеш“.

## Техника

- Next.js + TypeScript + Tailwind + shadcn/ui
- Prisma + SQLite (`prisma/dev.db`)
- Сесии: `iron-session` (signed httpOnly cookie)
- Каталог: 2 срока · 10 теми · 42 урока · 126 нива · 630 станции

## Команди

```bash
npm run db:seed      # презареди демо данните
npm run db:reset     # миграции + seed отначало
npm run build
npm start
```
