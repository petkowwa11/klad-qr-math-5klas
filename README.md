# КЛАД · Лов на съкровища

Практическа уеб-среда към магистърската теза на **Тони Петкова** — методически модел **„Лов на съкровища“** за самостоятелна работа по математика в **5. клас** чрез QR станции.

Учителят избира урок (или създава собствен лов), разпечатва QR кодове. Ученикът сканира, решава задачата, въвежда отговор, получава обратна връзка и продължава към следващата станция.

## Стек

- Next.js (App Router) + TypeScript + Tailwind CSS + shadcn/ui
- Без акаунт и без база: каталогът е вграден; собствените ловни се пазят в `localStorage`
- QR връзките към каталога са къси (`/play?c=…&lv=…&n=…`)

## Стартиране локално

```bash
npm install
npm run dev
```

Отвори **http://127.0.0.1:3847**.

Други команди:

```bash
npm run build    # продукционен билд
npm start        # старт след build (порт 3847)
npm run curriculum:generate   # пресъздава src/data/curriculum.json
```

## Потоци

### Учебна програма (основен сценарий)
1. `/curriculum` — срокове → теми → уроци (търсене по ключова дума).
2. Отвори урок → избери ниво **Лесно / Средно / Трудно**.
3. Разгледай станциите или таб **QR лист** (печат / изтегляне).
4. Ученикът отваря станция през QR → задача → отговор → **Провери**.

### Ученик
- Въвежда отговор; при грешка може да опита отново.
- Подсказка по желание; след няколко грешни опита може да разкрие верния отговор.
- „Следваща станция“ се отключва след верен отговор.
- Напредъкът се пази локално в браузъра.

### Учител (собствени ловни)
- `/teacher` — създаване/редакция на маршрути извън каталога.
- Всяка станция: заглавие, задача, **верен отговор**, приети варианти, подсказка.
- QR лист и преглед за ученик (`preview=1` позволява учителски пропуск).

## Съдържание (5. клас)

| | Брой |
| --- | ---: |
| Срокове | 2 |
| Теми | 10 |
| Уроци | 42 |
| Нива | 126 |
| Станции със задачи и отговори | 630 |

Теми включват: натурални числа, делимост, обикновени и десетични дроби, проценти, ъгли, триъгълници, четириъгълници, периметър и лице, мерни единици, обем, координати, уравнения, данни и годишни преговори.

Каталогът се генерира от `scripts/generate-curriculum.mjs` → `src/data/curriculum.json`.

## Маршрути

| Път | Роля |
| --- | --- |
| `/` | Начална страница (бранд КЛАД) |
| `/curriculum` | Учебна програма |
| `/curriculum/[lessonId]` | Нива, станции, QR лист |
| `/play?c=&lv=&n=` | Ученическа станция от каталога |
| `/play?d=&n=` | Ученическа станция от кодиран собствен лов |
| `/teacher` | Собствени ловни маршрути |
| `/teacher/[id]` | Редакция на лов |

## Бележка за тезата

КЛАД е **практическата част** към модела „Лов на съкровища“: независима математическа работа чрез физически станции и цифрови задачи. Подходящ за урок, занималня или открит урок в 5. клас. Не замества учебника — организира самостоятелния маршрут около конкретни умения.

## Лиценз / употреба

Учебен прототип за магистърска теза. За споделяне в клас — клонирай хранилището и стартирай локално или деплойни на Vercel (виж по-долу).

### Деплой на Vercel (препоръчително)

1. Отвори [vercel.com/new](https://vercel.com/new) и влез с GitHub акаунта си.
2. **Import** хранилището `petkowwa11/klad-qr-math-5klas`.
3. Остави настройките по подразбиране (Next.js се разпознава автоматично) → **Deploy**.

Публичният URL ще е от вида `https://klad-qr-math-5klas.vercel.app`.
